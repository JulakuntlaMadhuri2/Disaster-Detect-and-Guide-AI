# Disaster Detect and Guide AI

AI-powered disaster preparedness platform using RAG and NLP providing emergency guidance, alert summarization, and multilingual support. 

## Problem Statement

During disasters such as floods, cyclones, earthquakes, and heatwaves, people often struggle to find accurate and actionable information quickly.

Disaster Detect and Guide AI aims to provide reliable guidance, alert summaries, and emergency planning assistance using AI.

## Planned Features

- Disaster-related Q&A
- Emergency alert summarization
- Risk assessment
- Emergency action plan generation
- Multilingual support (English & Telugu)
- Source-based responses

## Tech Stack

- Python
- FastAPI
- LangChain
- FAISS
- React
- Git & GitHub
